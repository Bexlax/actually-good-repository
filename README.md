## Mod that brings some of Terraria's inventory mechanics to Minecraft. Currently includes:

- Bigger stack sizes (up to 460)
- Favorite items
- Armor loadout (kinda compatible with Curios)
- New item highlight
- Sorting
- Quick/Similar stack to chests
- Loot/Deposit all
- Restock

### recommended mods:

- Stxck (without this, dropped items don't merge if they exceed the 64 stack count)
- TrashSlot (adds the same trashslot functionality from terraria. also it's compatible with favorite items)

there might be some issues/incompatibilities, reporting them in my github would be greatly appreciated
